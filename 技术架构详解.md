## 1. 文档处理流程

### 1.1 文档解析
不同格式的文档需要不同的解析器：

```python
# PDF 解析
import PyPDF2
from pdfminer.high_level import extract_text

def parse_pdf(file_path):
    """提取 PDF 文本，保留页码信息"""
    text_by_page = []
    with open(file_path, 'rb') as file:
        pdf_reader = PyPDF2.PdfReader(file)
        for page_num, page in enumerate(pdf_reader.pages):
            text = page.extract_text()
            text_by_page.append({
                'page': page_num + 1,
                'content': text
            })
    return text_by_page

# TXT/Markdown 解析
def parse_text(file_path):
    """解析纯文本，按段落分割"""
    with open(file_path, 'r', encoding='utf-8') as f:
        content = f.read()
    return content

# DOCX 解析
from docx import Document

def parse_docx(file_path):
    """解析 Word 文档"""
    doc = Document(file_path)
    paragraphs = [para.text for para in doc.paragraphs if para.text.strip()]
    return '\n\n'.join(paragraphs)
```

**关键技术点：**
- 保留**元数据**：页码、标题层级、表格位置等
- 处理**特殊内容**：表格、图片（OCR）、公式
- **编码处理**：统一使用 UTF-8

### 1.2 文档分块（Chunking）

为什么需要分块？
- LLM 有 token 限制，不能把整个文档一次性输入
- 小块文本的向量表示更精确
- 检索时可以只返回相关片段

**分块策略：**

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter

def chunk_document(text, chunk_size=500, chunk_overlap=50):
    """
    智能分块策略
    chunk_size: 每块的字符数
    chunk_overlap: 块之间的重叠字符数（保持上下文连贯）
    """
    text_splitter = RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,
        chunk_overlap=chunk_overlap,
        separators=["\n\n", "\n", "。", ".", " ", ""]  # 优先按段落分割
    )
    chunks = text_splitter.split_text(text)
    return chunks
```

**分块的权衡：**
- **块太大**：检索不精确，超过模型上下文限制
- **块太小**：丢失上下文，语义不完整
- **最佳实践**：中文 300-800 字，英文 500-1000 词，overlap 10-20%

**高级分块技术：**
```python
def semantic_chunking(text, model):
    """
    基于语义相似度的智能分块
    在语义转折点切分，而不是机械地按字数
    """
    sentences = split_into_sentences(text)
    embeddings = model.encode(sentences)
    
    chunks = []
    current_chunk = [sentences[0]]
    
    for i in range(1, len(sentences)):
        # 计算相邻句子的相似度
        similarity = cosine_similarity(embeddings[i-1], embeddings[i])
        
        if similarity < 0.7:  # 语义转折点
            chunks.append(' '.join(current_chunk))
            current_chunk = [sentences[i]]
        else:
            current_chunk.append(sentences[i])
    
    chunks.append(' '.join(current_chunk))
    return chunks
```

## 2. 向量化和 Embedding 技术

### 2.1 什么是 Embedding？

**核心概念：** 将文本转换成高维向量（通常是几百到几千维），语义相似的文本在向量空间中距离更近。

```python
from sentence_transformers import SentenceTransformer

# 加载预训练模型
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

# 文本转向量
text1 = "机器学习是人工智能的一个分支"
text2 = "深度学习属于机器学习的子领域"
text3 = "今天天气很好"

embeddings = model.encode([text1, text2, text3])
# 输出: shape = (3, 384)  # 384维向量

# 计算相似度
from sklearn.metrics.pairwise import cosine_similarity

sim_1_2 = cosine_similarity([embeddings[0]], [embeddings[1]])[0][0]
sim_1_3 = cosine_similarity([embeddings[0]], [embeddings[2]])[0][0]

print(f"text1 和 text2 相似度: {sim_1_2:.3f}")  # ~0.85
print(f"text1 和 text3 相似度: {sim_1_3:.3f}")  # ~0.15
```

### 2.2 推荐的 Embedding 模型

**中文场景：**
1. **`paraphrase-multilingual-MiniLM-L12-v2`** （推荐新手）
   - 多语言支持，中文效果好
   - 速度快，384维
   - 本地运行，无需 API

2. **`BAAI/bge-large-zh-v1.5`** （推荐生产）
   - 智源出品，中文SOTA
   - 1024维，效果最好
   - 需要 4GB+ 显存

3. **OpenAI `text-embedding-3-small`** （云端）
   - API 调用，按使用付费
   - 1536维，多语言效果好

**性能对比：**

## 3. RAG 核心原理

### 3.1 什么是 RAG？

**RAG = Retrieval-Augmented Generation（检索增强生成）**

传统 LLM 的问题：
- 只能回答训练数据中的知识
- 容易"幻觉"（编造不存在的信息）
- 无法访问私有文档

RAG 的解决方案：
1. **检索（Retrieve）**：从知识库中找到相关文档
2. **增强（Augment）**：将文档作为上下文提供给 LLM
3. **生成（Generate）**：LLM 基于文档生成答案

### 3.2 RAG 完整流程

```python
def rag_pipeline(user_question, vector_db, llm):
    """
    完整的 RAG 流程
    """
    # Step 1: 检索相关文档
    relevant_chunks = vector_db.search(
        query=user_question,
        top_k=5  # 取最相关的5个块
    )
    
    # Step 2: 构建 Prompt
    context = "\n\n".join([
        f"[文档片段 {i+1}]\n{chunk.content}\n来源: {chunk.metadata['doc_name']} 第{chunk.metadata['page']}页"
        for i, chunk in enumerate(relevant_chunks)
    ])
    
    prompt = f"""你是一个专业的文档问答助手。请基于以下文档内容回答用户的问题。

相关文档内容：
{context}

用户问题：{user_question}

要求：
1. 只基于提供的文档内容回答
2. 如果文档中没有相关信息，请明确说明
3. 回答时引用具体的文档来源

回答："""
    
    # Step 3: 调用 LLM 生成答案
    answer = llm.generate(prompt)
    
    # Step 4: 返回答案和来源
    return {
        'answer': answer,
        'sources': relevant_chunks
    }
```

```python
def hybrid_search(query, vector_db):
    """
    结合向量检索和关键词检索
    """
    # 向量检索（语义相似）
    semantic_results = vector_db.similarity_search(query, top_k=10)
    
    # 关键词检索（BM25算法）
    keyword_results = bm25_search(query, top_k=10)
    
    # 融合两种结果（RRF算法）
    final_results = reciprocal_rank_fusion(
        [semantic_results, keyword_results],
        weights=[0.7, 0.3]  # 语义权重更高
    )
    
    return final_results[:5]
```

**3. 重排序（Re-ranking）**
```python
from sentence_transformers import CrossEncoder

def rerank_results(query, chunks, top_k=5):
    """
    使用交叉编码器对检索结果重新排序
    """
    reranker = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')
    
    # 计算每个块与查询的相关性分数
    pairs = [[query, chunk.content] for chunk in chunks]
    scores = reranker.predict(pairs)
    
    # 按分数排序
    ranked_chunks = sorted(
        zip(chunks, scores),
        key=lambda x: x[1],
        reverse=True
    )
    
    return [chunk for chunk, score in ranked_chunks[:top_k]]
```

**4. 上下文窗口优化**
```python
def expand_context(selected_chunk, all_chunks):
    """
    检索到某个块后，自动包含其前后的块
    保持上下文完整性
    """
    chunk_id = selected_chunk.metadata['chunk_id']
    doc_id = selected_chunk.metadata['doc_id']
    
    # 找到同一文档的前后块
    expanded = []
    for chunk in all_chunks:
        if chunk.metadata['doc_id'] == doc_id:
            if abs(chunk.metadata['chunk_id'] - chunk_id) <= 1:
                expanded.append(chunk)
    
    # 按原文顺序排序
    expanded.sort(key=lambda x: x.metadata['chunk_id'])
    return expanded
```

## 4. 引用溯源实现

### 4.1 为什么需要引用溯源？

NotebookLM 的核心特色：每个回答都能追溯到原文档的具体位置。

**实现方法：**

```python
class CitationTracker:
    def __init__(self):
        self.citations = []
    
    def add_citation(self, chunk, relevance_score):
        """记录引用"""
        self.citations.append({
            'doc_name': chunk.metadata['doc_name'],
            'page': chunk.metadata['page'],
            'content_preview': chunk.content[:100] + '...',
            'char_start': chunk.metadata['char_start'],
            'char_end': chunk.metadata['char_end'],
            'relevance': relevance_score
        })
    
    def format_citations(self):
        """格式化引用列表"""
        citations_text = "\n\n引用来源：\n"
        for i, cite in enumerate(self.citations, 1):
            citations_text += f"[{i}] {cite['doc_name']} 第{cite['page']}页\n"
            citations_text += f"    原文: {cite['content_preview']}\n"
        return citations_text

# 在生成答案时使用
def rag_with_citations(question, vector_db, llm):
    tracker = CitationTracker()
    
    # 检索
    chunks = vector_db.search(question, top_k=5)
    
    # 记录引用
    for chunk in chunks:
        tracker.add_citation(chunk, chunk.score)
    
    # 生成答案（在 prompt 中要求标注引用）
    context = "\n\n".join([
        f"[来源{i+1}] {chunk.content}"
        for i, chunk in enumerate(chunks)
    ])
    
    prompt = f"""基于以下文档回答问题，并在答案中用 [来源1]、[来源2] 标注引用位置。

{context}

问题：{question}

答案（请在引用事实时标注来源编号）："""
    
    answer = llm.generate(prompt)
    
    return {
        'answer': answer,
        'citations': tracker.format_citations()
    }
```

### 4.2 高亮显示引用位置

```javascript
// 解析答案中的引用标记
function parseAnswerWithCitations(answer) {
    const citationRegex = /\[来源(\d+)\]/g;
    const parts = [];
    let lastIndex = 0;
    let match;
    
    while ((match = citationRegex.exec(answer)) !== null) {
        // 添加普通文本
        parts.push({
            type: 'text',
            content: answer.slice(lastIndex, match.index)
        });
        
        // 添加引用标记
        parts.push({
            type: 'citation',
            number: parseInt(match[1]),
            content: match[0]
        });
        
        lastIndex = match.index + match[0].length;
    }
    
    // 添加剩余文本
    parts.push({
        type: 'text',
        content: answer.slice(lastIndex)
    });
    
    return parts;
}

                        key={i}

                    >
                        {part.content}
                    </span>
                ) : (
                    <span key={i}>{part.content}</span>
                )
            )}
        </div>
    );
}
```

## 5. 多文档关联分析

### 5.1 核心思路

当用户上传多个文档时，系统应该能够：
- 发现文档之间的**共同主题**
- 找出**矛盾**或**互补**的观点
- 构建跨文档的**知识图谱**

### 5.2 文档相似度矩阵

```python
def compute_document_similarity(documents, embedder):
    """
    计算文档之间的相似度矩阵
    """
    # 为每个文档生成整体向量（平均所有chunk的向量）
    doc_embeddings = []
    for doc in documents:
        chunk_embeddings = embedder.encode(doc.chunks)
        # 取平均作为文档向量
        doc_vector = np.mean(chunk_embeddings, axis=0)
        doc_embeddings.append(doc_vector)
    
    # 计算相似度矩阵
    similarity_matrix = cosine_similarity(doc_embeddings)
    
    # 可视化
    import seaborn as sns
    import matplotlib.pyplot as plt
    
    plt.figure(figsize=(10, 8))
    sns.heatmap(
        similarity_matrix,
        xticklabels=[doc.name for doc in documents],
        yticklabels=[doc.name for doc in documents],
        annot=True,
        cmap='YlOrRd'
    )
    plt.title('文档相似度热力图')
    plt.show()
```

### 5.3 主题聚类

```python
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA

def cluster_documents(documents, embedder, n_clusters=3):
    """
    将文档按主题聚类
    """
    # 获取所有chunk的向量
    all_chunks = []
    chunk_to_doc = []
    
    for doc in documents:
        for chunk in doc.chunks:
            all_chunks.append(chunk.content)
            chunk_to_doc.append(doc.name)
    
    embeddings = embedder.encode(all_chunks)
    
    # KMeans聚类
    kmeans = KMeans(n_clusters=n_clusters, random_state=42)
    cluster_labels = kmeans.fit_predict(embeddings)
    
    # 为每个聚类生成主题摘要
    clusters = {}
    for i in range(n_clusters):
        cluster_chunks = [
            all_chunks[j] for j in range(len(all_chunks))
            if cluster_labels[j] == i
        ]
        
        # 用LLM总结这个聚类的主题
        summary = llm.generate(f"""
        以下是一组相关的文档片段，请总结它们的共同主题：
        
        {chr(10).join(cluster_chunks[:5])}  # 只取前5个代表性片段
        
        主题摘要（10字以内）：
        """)
        
        clusters[summary] = {
            'chunks': cluster_chunks,
            'documents': list(set([
                chunk_to_doc[j] for j in range(len(all_chunks))
                if cluster_labels[j] == i
            ]))
        }
    
    return clusters
```

### 5.4 跨文档问答

```python
def cross_document_qa(question, documents, vector_db, llm):
    """
    跨文档问答：综合多个文档的信息
    """
    # 从所有文档中检索相关片段
    all_chunks = []
    for doc in documents:
        chunks = vector_db.search(
            query=question,
            filter={'doc_id': doc.id},
            top_k=3
        )
        all_chunks.extend(chunks)
    
    # 按相关性排序
    all_chunks.sort(key=lambda x: x.score, reverse=True)
    top_chunks = all_chunks[:10]
    
    # 按文档分组
    chunks_by_doc = {}
    for chunk in top_chunks:
        doc_name = chunk.metadata['doc_name']
        if doc_name not in chunks_by_doc:
            chunks_by_doc[doc_name] = []
        chunks_by_doc[doc_name].append(chunk)
    
    # 构建跨文档对比的prompt
    context = ""
    for doc_name, chunks in chunks_by_doc.items():
        context += f"\n## 文档: {doc_name}\n"
        for chunk in chunks:
            context += f"- {chunk.content}\n"
    
    prompt = f"""你需要综合多个文档的信息来回答问题。

文档内容：
{context}

问题：{question}

要求：
1. 综合所有文档的观点
2. 如果不同文档有矛盾，请明确指出
3. 标注每个信息的来源文档

回答："""
    
    answer = llm.generate(prompt)
    
    return {
        'answer': answer,
        'sources_by_document': chunks_by_doc
    }
```

```python
"""
        response = llm.generate(prompt)
        key_points[doc.name] = json.loads(response)['points']
    
    # 两两比较，寻找矛盾
    contradictions = []
    docs = list(documents)
    
    for i in range(len(docs)):
        for j in range(i+1, len(docs)):
            doc1, doc2 = docs[i], docs[j]
            
            prompt = f"""比较以下两组观点，找出是否存在矛盾：

文档A ({doc1.name}) 的观点：
{chr(10).join(key_points[doc1.name])}

文档B ({doc2.name}) 的观点：
{chr(10).join(key_points[doc2.name])}

是否存在矛盾？如果有，请具体说明。
以JSON格式返回：{{"has_contradiction": true/false, "description": "..."}}
"""
            result = json.loads(llm.generate(prompt))
            
            if result['has_contradiction']:
                contradictions.append({
                    'doc1': doc1.name,
                    'doc2': doc2.name,
                    'description': result['description']
                })
    
    return contradictions
```
